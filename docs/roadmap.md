## How to use this file

- Add one item per row or subsection.
- State the user problem before the solution.
- Mark the status as `Proposed`, `Approved`, `In progress`, `Done`, or `Dropped`.
- Link to an issue, design note, or code change when one exists.
- Move completed work into the current documentation.

## Current baseline

- 28 prototype spot records in a local TypeScript file.
- Browser-only catalog search and filtering.
- Grid, list, and map views.
- Detail pages with schedules, facilities, related places, and route links.
- Bookmarks, recent searches, and report submissions stored in `localStorage`.
- No database, API, authentication, or admin workflow.
- No full offline mode or service worker.
