## Note on Unsplash

The sample records use image URLs on `images.unsplash.com`. The Unsplash homepage returned HTTP 401 to the automated request during this check. That response can be a bot-protection response, but it is not proof that the site is available in a normal browser. This documentation therefore does not present the Unsplash homepage as a verified reference link.

## Link policy

- Use official project documentation when explaining a dependency.
- Check a link before adding it to a document.
- Record the check date when the status matters.
- Do not use a link as proof of a product claim unless the linked source supports that claim.
